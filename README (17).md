# ⚔️ Морской Бой 10×10 (PvP & PvE)

Современная, стильная и полностью автономная веб-игра **«Морской Бой»** на сетке 10×10 клеток. Работает прямо в браузере, не требует установки дополнительных программ и серверов.

---

## 🚀 Особенности проекта

- **🤖 PvE (Игра против бота):** Одиночный режим с искусственным интеллектом для быстрого боя.
- **👥 PvP (Дуэль с другом):** Игра для двоих с разных устройств (ПК, смартфона или планшета) в одной сети Wi-Fi или через интернет по коду комнаты.
- **🔊 Озвучка Web Audio API:** Динамическая генерация звуков выстрелов, попаданий и промахов без использования внешних файлов.
- **🎨 UX/UI дизайн:** Современная тёмная тема на базе **Tailwind CSS**.
- **💧 Удобство боя:** Автоматическая отметка промахов вокруг полностью уничтоженного корабля.

---

## 🛠️ Стек технологий

* **HTML5** — структура интерфейса и сетки полей.
* **Tailwind CSS** — стилизация и адаптивная верстка.
* **JavaScript (ES6+)** — логика игры, алгоритмы проверок и выстрелов.
* **PeerJS (WebRTC)** — связь игроков на разных устройствах без стороннего сервера.
* **Web Audio API** — генерация аудиоэффектов прямо в браузере.

## 🎮 Как запустить

1. Откройте файл `index.html` в любом современном браузере.
2. Для игры по сети (PvP):
   - Первый игрок выбирает **«PvP с Другом»** и копирует свой **ID комнаты**.
   - Второй игрок вставляет полученный ID в поле и нажимает **«Войти»**.
3. Расставьте корабли вручную или нажмите **«Авто-расстановка»**.
4. Нажмите **«Начать бой!»** и уничтожьте флот соперника!

---

## 🌐 Деплой на GitHub Pages

1. Загрузите файлы `index.html` и `README.md` в ваш репозиторий на GitHub.
2. Перейдите в **Settings** -> **Pages**.
3. В поле **Source** выберите ветку `main` (или `master`) и нажмите **Save**.
4. Игра доступна по ссылке вида `https://username.github.io/repository-name/`.
